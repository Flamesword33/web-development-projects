#Workout-center-app

## What is the Workout-Center-app

A companion app to assist in using multiple gym machines correctly. Originally developed for the Camrose fitness center. Ported from Android to html.

## Installation

1. Download workout-app.zip
2. Extract the folder
3. Run workout-app.html

## Usage

You will start at a title screen. Simply click the image to begin.

![Fitness Center](https://github.com/Flamesword33/web-development-projects/blob/main/2024/workout-app/demo/title-screen.jpg)

Next you will be greeted with the main menu. In here you may:
1. Select a muscle group to proceed
2. Select the Directions link or The Fitness Centre logo to go to a map page

![Main menu](https://github.com/Flamesword33/web-development-projects/blob/main/2024/workout-app/demo/muscle-groups.jpg)

If you selected a muscle group you will be greeted with a series of machines.
Again you may:
1. Select a machine to see its info page
2. Select the back arrow to return to the main menu
3. Select the Directions link or the Fitness Centre Logo to go to a map page

![machine page](https://github.com/Flamesword33/web-development-projects/blob/main/2024/workout-app/demo/machines.jpg)

Selecting a machine proceeds to a video and text breakdown of the machine. 
It also includes a back arrow to return to the main menu.

![machine info page](https://github.com/Flamesword33/web-development-projects/blob/main/2024/workout-app/demo/machine-info.jpg)

Finally the map page shows the location of the Camrose Fitness Centre

![Map](https://github.com/Flamesword33/web-development-projects/blob/main/2024/workout-app/demo/map.jpg)
