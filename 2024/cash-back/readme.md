# Cash-Back

## What is Cash-Back

A website based simulator to teach a user to run a cash register. 

![cash-back-home-screen](https://github.com/Flamesword33/web-development-projects/blob/main/2024/cash-back/demo%20pictures/Default-game.jpg) 

## To Run

1. Download cash-back.zip
2. Extract
3. open: cash-back.html

## Failure states

If you over pay you will be met with a game over screen:

![Total:173.65 customer payed: 668.22 Amount payed so far: 494.6](https://github.com/Flamesword33/web-development-projects/blob/main/2024/cash-back/demo%20pictures/Overpay%20%5B1%5D.jpg)

![You're giving them too much! Try again](https://github.com/Flamesword33/web-development-projects/blob/main/2024/cash-back/demo%20pictures/Overpay.jpg)

If you under pay a similar popup will occur:

![Stop stealing from the customer.](https://github.com/Flamesword33/web-development-projects/blob/main/2024/cash-back/demo%20pictures/Underpay.jpg)

In both cases the game will reset your amount and give you another chance to solve the given problem. 

## Win condition

If you get the total exactly right you will be met with a victory screen:

![Good work!](https://github.com/Flamesword33/web-development-projects/blob/main/2024/cash-back/demo%20pictures/Correct%20amount.jpg)

At which point the game will reset. A new item price will be selected and a new customer total will be created.
